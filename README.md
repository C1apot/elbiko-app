# Elbiko — downloads

This repository holds **only published builds** for [Elbiko](https://github.com/C1apot/Elbiko):
the Windows installer, the Android APK, and `latest.json`, the file the app reads
to check for updates.

The source code lives in a private repository; nothing about it is here.

## Downloads

- **Windows**: `Elbiko_Setup.exe` (x64, Windows 10/11)
- **Android**: `Elbiko_Android.apk` (Android 6.0+, debug-signed — sideload only)

Both are also attached to every release. The app updates itself from the newest
release: Windows downloads and installs in place, Android hands the APK to the
system installer.

## What `latest.json` is

It is Tauri's updater manifest plus a few extra keys the app uses:

| key | used for |
|---|---|
| `version`, `notes`, `pub_date` | the in-app "update available" strip and the release notes |
| `platforms.windows-x86_64` | signature + URL of the signed installer |
| `android.url` | the APK the Android build downloads |
| `setup` | the same installer, for a manual download |
| `page` | where "Release notes" points |

It is generated by `npm run release:update` in the private repo, from the exact
artifacts uploaded here.
